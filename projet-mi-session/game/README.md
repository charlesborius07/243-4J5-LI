# MQTT Labyrinth Game

Ce projet est un jeu d'adresse basé sur le LilyGo T-SIM A7670G.

## Commandes
- **Inclinez** l'ESP32 pour déplacer la bille dans le labyrinthe (via MPU6050).
- **Potentiomètre 1** : Ajuste la friction (vitesse).
- **Potentiomètre 2** : Ajuste la taille/difficulté du labyrinthe.
- **Bouton 1** : Relancer le niveau.
- **Bouton 2** : Pause.

## Feedback
- **LED 1 (Rouge)** : Vies restantes.
- **LED 2 (Verte)** : Niveau complété.
- **LED 3 (Jaune)** : Aide.
- **LED 4 (Bleue)** : Mode Vitesse.
